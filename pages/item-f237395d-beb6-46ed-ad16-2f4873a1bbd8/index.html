8c. Pitfall baru (penting)

  1. node_field_revision wajib ikut dicopy saat restore node via SQL — tanpa itu entity load dengan title/status kosong tanpa error (base fields baca dari tabel revisi itu, bukan node_field_data).
  2. cache_entity menaungi hasil query — entity stale di cache bin itu dipakai lebih dulu; saat debug hapus baris values:node:<nid> (atau drush cr) sebelum menyimpulkan DB salah.
  3. Pathauto menimpa alias manual — $node->path->alias = '/lesson/bersiap' jadi /bersiap setelah save. Solusi: buat alias lewat entity API path_alias setelah node disimpan.
  4. File entity ber-URI eksternal berfungsi — File::create(['uri' => 'https://...']) + file_create_url() mengembalikan URL asli; cocok untuk permintaan “gambar url asli”. Catatan: skilling.us memblokir User-Agent non-browser untuk file statis (curl 404, browser UA 200) — URL hotlinked tetap tampil untuk pengunjung asli.
  5. Markup gambar skilling: !(classes)<img alt=\"...\" src=\"URL\" />! (parser konversi ke skilling-parser-image); bentuk Markdown ![alt](url) tidak dikenali.
  6. Jangan wipe karakter/MIQ secara membabi buta — direktif character./mcq. mencari node sendiri by field_internal_name; saat reset konten clone, pertahankan (atau pulihkan dari DB sumber) node type character dan mcq.
