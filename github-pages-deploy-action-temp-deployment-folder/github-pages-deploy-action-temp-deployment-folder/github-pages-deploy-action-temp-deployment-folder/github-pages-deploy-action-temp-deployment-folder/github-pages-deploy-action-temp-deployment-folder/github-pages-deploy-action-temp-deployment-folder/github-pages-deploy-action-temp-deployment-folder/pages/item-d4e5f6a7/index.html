8. Pelajaran yang terbukti

  • Node harus disimpan dengan status=1 dan alias langcode=en; kalau tidak, halaman 404 walau node ada.
  • pathauto menghapus alias manual pada setiap save, termasuk save dari book.manager. Alias harus dipasang ulang setelah semua save selesai.
  • Baris book tidak boleh di-INSERT mentah: kolom p1..p9 harus diisi lewat book.manager->updateOutline(), kalau tidak navigasi prev/next kosong. Kalau sudah terlanjur, hapus barisnya lalu rebuild lewat API.
  • Drush hanya ada di d8_fpm; perintah harus dipipe ke sh -s, bukan dikutip bersarang di dalam ssh "...".

10. Koreksi: tag reflect. didukung

Versi pertama halaman ini mengganti refleksi dengan paragraf statis karena dianggap butuh content type reflect_note. Itu salah. Modul Skilling merender skilling-reflect-container tanpa node tujuan sama sekali — bukti: node 345 (contoh-refleksi) dan node 344 memakai tag yang sama.

reflect.

  internal_name=reflect_kode_1



  Apa yang dilakukan kode ini?

/reflect.
  • Baris pembuka reflect. wajib. Menulis hanya internal_name=... lalu /reflect. tidak merender apa pun.
  • Judul "Reflect" dan baris bantuan bahasa Inggris dicetak otomatis oleh widget.
  • Verifikasi: grep -c skilling-reflect-container pada halaman = jumlah blok (node 344 → 4, id 344-reflect_kode_1..4).
  • Blok tidak boleh disisipkan ke HTML hasil render dengan offset string: percobaan itu mendarat di dalam <div class="skilling-insert-character"> dan merusak tata letak. Bangun ulang body dari builder lalu simpan node.
