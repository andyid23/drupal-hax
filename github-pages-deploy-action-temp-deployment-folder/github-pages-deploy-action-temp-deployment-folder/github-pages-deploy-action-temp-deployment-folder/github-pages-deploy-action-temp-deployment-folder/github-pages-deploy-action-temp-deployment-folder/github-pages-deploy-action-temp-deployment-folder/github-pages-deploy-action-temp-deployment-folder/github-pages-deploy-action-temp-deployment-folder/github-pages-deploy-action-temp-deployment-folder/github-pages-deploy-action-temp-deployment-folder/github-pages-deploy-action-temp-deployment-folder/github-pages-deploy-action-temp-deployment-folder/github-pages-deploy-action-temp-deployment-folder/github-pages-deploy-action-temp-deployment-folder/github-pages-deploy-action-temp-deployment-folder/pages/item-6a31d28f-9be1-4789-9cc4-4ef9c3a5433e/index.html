Bisa "rubah gambar jadi Indonesia"?

Tidak bisa otomatis. Gambar-gambar ini adalah screenshot perangkat lunak (Excel, VBE, cPanel, phpMyAdmin, Chrome DevTools) — teks Inggrisnya "terbakar" di dalam piksel. Opsi:

  • Biarkan Inggris — praktik umum di pendidikan TI Indonesia (istilah menu tetap Inggris saat praktik nyata).
  • Re-screenshot manual dengan UI bahasa Indonesia, satu per satu — kerja manusia, tidak terotomasi. Struktur folder lokal (F1) memudahkan ini: ganti file dengan nama sama, langsung live.
  • Foto/diagram (kambing, karakter, diagram alur) tidak berteks — tidak perlu diubah.

Path folder sendiri untuk dimodifikasi

Ya. F1 menempatkan file di docroot bersama: di dalam container /var/www/html2/drupal8/web/skilling/<domain>/sites/default/files/…, di host /data/compose/34/drupal8-src/web/skilling/… (bind mount — bertahan lintas rebuild container). File biasa: bisa diedit, diganti, atau dihapus kapan saja, efeknya langsung live (file statis nginx).

webappexamples (PHP live) bisa diinstall lokal?

Bisa. Sumbernya PHP murni + sebagian butuh MySQL. Dua opsi:

  • Opsi A (disarankan): pakai php-fpm yang sudah ada. nginx drupal_web_server sudah meneruskan semua .php ke d8_fpm:9000 (PHP 7.4) dengan $document_root = docroot bersama — cukup taruh file di web/phpexamples/… dan langsung dieksekusi, tanpa container baru. Database: mariadb (drupal_database) sudah ada — buat DB contoh, import dump yang disediakan sumber (goats.sql.zip, nobody-db.sql, dsb.), atur kredensial lewat file konfig kecil.
  • Opsi B: container php:apache terpisah — isolasi lebih bersih; tambah service compose + routing.

Risiko: kode PHP lawas (era 2020, PHP 7.x — fpm 7.4 cocok); app ber-DB perlu edit kredensial; unduhan = seluruh pohon situs (dicroawl saat build, diperkirakan puluhan MB).
