Kloning Web Python
------------------

Ini adalah laporan halaman baru yang mengabadikan proses kloning otomatis situs web Skilling (python, webapps, vba) ke Drupal multisite menggunakan pipeline yang sepenuhnya otonom.

### Langkah

*   **Klon Antrian** – \`crawl\_queue.py\` mengekstrak 260 pelajaran (vba:62, python:73, webapps:125) dari sumber aslinya (vba.skilling.us, python.skilling.us, webapps.skilling.us) ke dalam `skilling-queue.json` yang digabungkan dan `*_queue.json` per-situs.
*   **Ekstraksi Blok** – \`extract\_blocks.py\` mengubah halaman HTML menjadi JSON berurut dari blok (img, p, h3, h4, char, pause, list, reflect, code).
*   **Terjemahan LLM** – \`hermes -z\` mengubah setiap blok (judul, tubuh) menjadi terjemahan Bahasa Indonesia dengan JSON ketat (`0_alt`, `1`, ...). File bersih disimpan ke `*.tr_raw.json.`
``*   **Buat Spesifikasi** – `build_body.py` menggabungkan blok asli dan terjemahan menjadi body HTML lengkap dengan karakter, gambar, pause, list, reflect, code. *   **Buat Lesson Node di Server** – `create_lesson.php` (drush CLI) menggunakan body yang dihasilkan untuk membuat node pelajaran Drupal baru (order, alias, judul). *   **Verifikasi Render** – periksa HTTP 200, hitung pause dan karakter, verifikasi di `http://127.0.0.1:8087/lesson/`. *   **Update Antrian** – `qset.py` menandai halaman sebagai `done` (atau `errored`) dengan catatan hasil. *   **HAXCMS Ops** – setelah halaman tersimpan di Drupal, `hax site node:add` menulis laporan terstruktur ke repositori HAXCMS (`github.com/andyid23/drupal-hax`) menggunakan antrian MINGGUAN untuk publikasi otomatis.``
